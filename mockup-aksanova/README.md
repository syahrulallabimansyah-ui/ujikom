## 🚀 Cara Import ke Figma (Menjadi Layer & Vector Editable):

1. Buka [**Figma**](https://www.figma.com/).
2. Buat file baru (*Design File*).
3. Buka menu **Plugins** ➔ cari plugin gratis: **`html.to.design`** (dibuat oleh *divriots*).
4. Di plugin tersebut:
   - Pilih opsi **Import HTML / Upload file**, lalu pilih berkas:  
     `c:\laragon\www\aksanovaphp_revisi_hell_hihi\mockup-aksanova\index.html`
   - *Atau* jika server Laragon aktif, masukkan URL:  
     `http://localhost/aksanovaphp_revisi_hell_hihi/mockup-aksanova/index.html`
5. Klik **Import**.
6. Dalam sekejap, seluruh landing page memanjang ke bawah akan ter-convert menjadi **Frame Figma Asli 1440px** lengkap dengan teks yang bisa diedit, warna HEX, dan komponen auto-layout!
